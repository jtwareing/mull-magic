# Mullaney's Kitchen

A fan-run quiz site for the Steven Mullaney faithful: name quizzes, Super Over, Career Mode and a gallery.

Match data covers 2014 to 2023 and comes from [Cricsheet](https://cricsheet.org). Each answer links to its Cricinfo scorecard. Progress is saved in each player's own browser.

Affectionate parody by fans; not affiliated with Steven Mullaney or Nottinghamshire CCC.
